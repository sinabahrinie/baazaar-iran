# Baazaar Iran

**Baazaar Iran** is a Persian-language online electronics store project built with HTML and CSS. The project provides a simple and user-friendly interface for browsing electronic products and viewing their details.

## Features

- Product listing page
- Individual product details pages
- Responsive and organized page layouts
- Persian language support (RTL)
- Custom styling with CSS
- Custom font integration

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
baazaar-iran/
├── product-details/
│   ├── product-details -keyboard.html
│   ├── product-details-camera.html
│   ├── product-details-headphone.html
│   ├── product-details-mag.html
│   ├── product-details-smartwatch.html
│   ├── product-details-speaker.html
│   └── style.css
├── product-list.html
├── style.css
├── image/
└── fonts/
```

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `product-list.html` in your web browser.
4. Browse the product listing and open individual product pages.

No additional dependencies or frameworks are required.

## Purpose

This project was created to practice and improve front-end web development skills using HTML and CSS.
